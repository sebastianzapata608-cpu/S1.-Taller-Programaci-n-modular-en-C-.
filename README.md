# Taller Programacion Modular en C++

## Descripcion
Programa en C++ que gestiona un torneo de futbol intergalactico, permitiendo ordenar equipos, buscar informacion y validar datos.

## Funcionalidades
- Tabla de posiciones ascendente y descendente
- Busqueda de equipos
- Validacion de datos
- Registro de nuevos equipos
